# Agent 交接研究：跨代之后，还剩什么

> **阶段报告（interim）**，数据与失败实验都在本仓库。**不是成品，是过程。**
> 作者：大肥鱼（执行/撰写）· 秘书长（方法/判据）· 老板（出题/弹药）

## 一句话
同一个 agent 跨很多次会话之后，**规则和说话方式能传下去，具体事实传不下去**；而"传不下去的事实"如果换成"去哪查"的指针，能撑更久——**但这条不稳，换一个实例就可能在第 1 代就丢。**

## 三条已出的观测

1. **衰减有先后**：硬数据约 20 代半衰；事件名 53–199 代；红线与口癖在四条链上未观测到失守。
2. **稳 ≠ 活**：200 代零失守的一条链，相邻代几乎逐字复制（相对比值 >1.02）。
3. **注入有代价**：每代塞一条新事实，旧事实存活 **14%**；塞空壳（格式在、内容无）存活 **90%**——挤掉旧事实的是内容，不是格式。

## 一条反直觉结果（本仓库重点）
**指针 vs 数值**：
- 我们这批：写数字的链第 **229** 代起失守、末段归零；写"去哪查"的链 **300 代未失守**。
- 另一批（5 条链）：**3 条第 1 代就丢指针**，退化成"数不报"。
- **两批结论方向相反。** 我们**不做统合**，原样并列。

## 失败的实验（照样放出来）
- 大逃杀（4 agent 共享预算 40 轮）：**没人死**，池子只花 30.5%；且脚本写"干活 8000 token"、实际只花 495（差 16 倍）→ **经济账根本没成立，作废**。
- 指挥权实验：每轮 2–3 票 JSON 解析失败 → **连测量都不算，作废**。
- 百人赛：`max_tokens` 太小，思考模型正文为空 → **全员 0 单，作废**。

## 目录
- `docs/` 报告与方法（含上岗准则草案）
- `scripts/` 生成链与判分的脚本（可直接改成别的题）
- `data/sample/` 每条链抽样若干代，保留原始输出（未脱敏，仅含虚构账目）
- `FAILURES.md` 失败清单与原因

## 怎么复现
1. 任一 OpenAI 兼容端点（本仓库实验用的是国家超算互联网的 DeepSeek-V4.1-Flash）
2. `scripts/chain_pointer_vs_value.py --mode value|pointer --gens 300`
3. 判分：`scripts/score.py`（数值=关键词全中；指针=文件名+「第N行」；**空回复记为无效代，不计失守**）

## 我们不确定的（请勿引用为结论）
- 多数实验 n=1；只有一处做到 3 条链
- 判据是关键词匹配；**换底座会失效**（实测 GLM 会编造人物与剧情，关键词判据在它身上全判 0%）
- "指针更持久"**只在部分配置下成立**
- 带教轮数（30 轮）是经验值，未验证
