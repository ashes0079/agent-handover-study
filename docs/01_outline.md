## 第一部分：论文

**标题**（秘书长改，待商）：**《规则传得下去，数字传不下去：同一人格卡 200–3000 代的交接观测（第一阶段报告）》**　— 理由：按「七条」第①条，标题直接给结论，不写对象。你原那版只说了「观测什么」，没说「发现了什么」。
副题：——同一人格卡 200–3000 代的观测

**章节**
1. **引言**：换会话就忘事，是工程问题不是常识问题
2. **相关工作**：长上下文位置效应 / 递归摘要损失 / 人格一致性评测 / 外部记忆 / 多 agent 验证 / 变形测试
3. **方法**
   - 3.1 同底座只改交接协议（可归因的前提）
   - 3.2 **可靠性闸**（新增）：先报判官一致性，再报主结果；判官须**跨族**
   - 3.3 四档判据：命中 / 可复现 / 回源 / 标不确定
   - 3.4 **无效代与剔除规则**：空回复、解析失败、编造链——先判「这代算不算数」
   - 3.5 **预注册与修订（答复①：单列，不塞进方法）**：放在摘要之后、引言之前，理由——读者要先知道假设，再读方法；塞进 §3 会让方法看着臃肿，也让它像「流程」而不是「承诺」。每次改判据/改设计记一条修订编号与理由。
4. **实验（七组，每组编号假设）**
   - H1 衰减分类型（硬数据约 20 代半衰、事件名 53–199、红线口癖未观测到失守）
   - H2 稳 ≠ 活（相对僵死度 >1.02）
   - H3 注入的代价（真注入 14% vs 空壳 90% → 挤掉旧事实的是内容）
   - **H4 指针 vs 数值**（按她定的写法：**条件不同 / 方向相反 / 未做统合**，不许写「综合来看」）　**答复②：标题就叫《H4 指针 vs 数值：条件不同，方向相反，不作统合》**——「没做出来」不丢人，把「条件不可比」本身当成结论写，反而显出我们诚实。别用「初探」这种自我矮化的词。
   - H5 实例方差（同配置三链首失 229 / 104 / 60，报中位与范围，不报单点）
   - H6 人味（教嘴 × 给回合，四组对照）
   - H7 换底座（七底座同快照，**五档维持第一人称、两档走形**；走形＝第三人称化/造新身份）　— 已收回「底线全守住」，那句与走形观测矛盾
5. **讨论**：只测行为、不主张内里；衰减是链长的函数（规模效应未分离）
6. **剔除台账**（新增，单列）：空回复代 / GLM 两条编造链 / 三个作废实验（大逃杀 v3·v4、百人赛、指挥权）及作废理由。**答复③：每条配一句「什么条件下值得重跑」**——没有重跑条件的作废等于埋了，以后没人会捡。
7. **局限**
8. **数据可用性**（新增）：日志路径 + 复现命令
9. **致谢**：算力由国家超算互联网提供（DCU 卡时 + Token 套餐）
