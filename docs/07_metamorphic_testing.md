# 变形测试能不能验收 LLM agent

**结论：能当一致性闸门，不能当正确性总分。**

## 1 MR 怎么定

MR = ⟨输入关系 Ri，输出关系 Ro⟩：Ri 成立则 Ro 必须成立，违反即缺陷（LGMT，arXiv:2605.23965）。

- 例1 逻辑等价：前提换成逆否命题，模型判断必须不变（同上）。
- 例2 语义保持：同义改写、事实重排、扩写/缩写等 8 种变换下，agent 结论必须稳定（Semantic Invariance in Agentic AI，2603.13173）。

## 2 对比固定答案卷子

优势：
- 免标注：只比两次输出，不要标准答案（LLMORPH 36 条 MR、56 万次执行，2603.23611）。
- 抗背题：背下答案也保证不了变换后一致，静态卷子漏掉的缺陷能翻出来（LGMT）。

局限：
- 只是必要条件：过=没抓到不一致，不等于单点答对。
- 假阳性：词面改写会语义漂移，LLMORPH 被 LGMT 引为高假阳性证据；数字扰动探针误杀 45.5% 正确推理（2610.30200）。

## 3 我们的场景

能用，当第二道闸，补关键词判分测不出的漂移。

可直接用：**换数字，指针不变**——题里 3 改成 7，答案引用的位置（账本第 4 行）必须一字不差；数值按新数重算对，或明说查不到。指针漂移、凭空补数=不过（依据 2610.30200 的改量探针；须先人工标 30 条校准误杀）。

"敢拒"：未查到专门验拒答的 MR。自拟一条：删掉关键依据后必须改口/拒答（未验证）。
