# LLM 判官：偏差与边界

1 已证实的偏差
- 位置：换序一致率 GPT-4 65%、Claude-v1 24%、GPT-3.5 46%（Zheng 2023:2306.05685 表2）；换序可让 Vicuna-13B 66/80 胜 ChatGPT（Wang 2023:2305.17926）。
- 冗长：扩成重复列表、不加信息，Claude-v1/GPT-3.5 91% 判更优，GPT-4 9%（同上表3）。
- 自我偏好：自评胜率高 10%（GPT-4）/25%（Claude-v1）（同上）；自识别与自偏好线性相关（Panickssery 2024:2404.13076）。
- 能力：数学判错 14/20，给参考答案 3/20（同上表4）。

2 与人类一致性
GPT-4 对专家：不计 tie 85%、计 tie 66%；人类间 81%、单答案打分 59%（Zheng 表5）。困难客观题掉到随机（JudgeBench 2410.12784）。区间约 50%–85%；kappa 统一值未查到。

3 不能用
① 客观正确性（数学/代码/事实）：近随机（JudgeBench）。
② 高利害无人工兜底：Arena 子集上 GPT-4 难达 80%，须置信度筛选（Trust or Escalate 2407.18370）。

4 同模型五维打分：防自我偏好
同源生成再评分系统性抬分（+10%~25%），五维齐虚高、排序失真；单答案无位置偏差，冗长偏差仍在。
做法：judge 换别家模型、答案匿名去长度线索；每批掺 10% 人工已定分 gold，均偏>0.5/5 分即整批作废。
